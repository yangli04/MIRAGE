# Estimate motif-specific on-target mutation rates using prior probability

`estimate_inference_with_prior` performs motif-aware inference using
motif prior probabilities, and estimates site-level mutation or
conversion signal along with posterior probabilities.

## Usage

``` r
estimate_inference_with_prior(
  chr.info,
  treatment_fixed_count,
  control_fixed_count,
  treatment_depth,
  control_depth,
  motif_specific = TRUE,
  delta = 0.001,
  depth.cutoff = 10,
  homo.cutoff = 0.99,
  bg.method = "fisher",
  highly.methyl.cutoff = 0.95,
  ref.freq.tab = NULL,
  seed = NULL,
  thread = 1,
  motif = "DRACH",
  Nmer = "5mer"
)
```

## Arguments

- chr.info:

  A `data.frame` with three columns: site position in the format
  "chrom_coordinate_strand" (e.g., chr1_14404\_-), site motif sequence
  (e.g., AAACC), and site motif type (e.g., NNUNN).

- treatment_fixed_count:

  A `vector` of non-mutation counts for each site in the treatment
  sample.

- control_fixed_count:

  A `vector` of non-mutation counts for each site in the control sample.

- treatment_depth:

  A `vector` of read coverage for each site in the treatment sample.

- control_depth:

  A `vector` of read coverage for each site in the control sample.

- motif_specific:

  Logical. Whether to estimate on-target mutation rates by motif. If
  `FALSE`, one overall mutation rate is estimated. Default is `TRUE`.

- delta:

  The sequencing error rate. Default is 0.001.

- depth.cutoff:

  The minimum read coverage for each site in the treatment and control
  sample. Default is 10.

- homo.cutoff:

  The minimum ratio of non-mutation counts for each site in the control
  sample that is used to determine homozygous sites. Default is 0.99.

- bg.method:

  The statistical test to infer the background sites. One of "binomial",
  "fisher", "lrt". Default is "fisher".

- highly.methyl.cutoff:

  The upper quantile cutoff of candidate signal sites used for
  estimating on-target mutation rates. This argument name is retained
  for backward compatibility. Default is 0.95.

- ref.freq.tab:

  A `data.frame` with motif frequencies in signal and background sets,
  plus the prior probability of each motif sequence. This table can be
  created by
  [`compute_prior`](https://yangli04.github.io/MIRAGE/reference/compute_prior.md)
  and must contain the columns "motif" and "prior_methylated".

- seed:

  A seed for the random number generators.

- thread:

  A positive integer numeric specifying the number of cores for parallel
  computing. Default is 1.

- motif:

  The target 5-mer motif pattern. MIRAGE expands supported degenerate
  bases internally. The default is "DRACH"; set this explicitly for the
  assay being analyzed.

- Nmer:

  The strategy for further grouping motifs. One of "5mer", "f4mer" or
  "l4mer". "5mer" will not consider further grouping strategy. In the
  "f4mer" and "l4mer" mode, all 5-mer motifs are grouped by sharing the
  same first or last 4-mer sequences, respectively. The argument is only
  used if `motif_specific = TRUE`.

## Value

A `list` including a `data.frame` of homozygous sites, a `data.frame` of
heterozygous sites, a `data.frame` of estimated on-target mutation rates
for each motif (lambda1), and the estimated background mutation rate
(lambda2).

## Details

`estimate_inference_with_prior` estimates site-level signal from motif
prior probabilities, which are usually obtained by
[`compute_prior`](https://yangli04.github.io/MIRAGE/reference/compute_prior.md).
The count table can be generated by any preprocessing pipeline as long
as it contains site IDs, motif annotations, treatment and control
fixed-base counts, and treatment and control read depths in the expected
order.

## Examples

``` r
# Estimate signal levels from a PAR-CLIP count table with motif priors.
count_table <- read.delim(system.file("extdata", "pos.read.count.example.parclip.txt",
                                      package = "MIRAGE"))

motif_counts <- table(count_table$motif)
motif_freq_exp <- data.frame(motif = names(motif_counts),
                             freq = as.numeric(motif_counts) / sum(motif_counts))
motif_freq_bg <- data.frame(motif = names(motif_counts),
                            tx_count = as.numeric(motif_counts),
                            genome_count = as.numeric(motif_counts))
motif_prior <- compute_prior(motif_freq_exp, motif_freq_bg, target_motif = "NNUNN",
                             target_base_index = 3, prob_methylation = 0.01)

res <- with(count_table, estimate_inference_with_prior(cbind(pos, motif, type),
            treated_fixed_count, control_fixed_count, treated_depth, control_depth,
            motif_specific = FALSE, delta = 0.001, depth.cutoff = 10,
            highly.methyl.cutoff = 0.95, ref.freq.tab = motif_prior,
            seed = 123, thread = 1, motif = "NNUNN", Nmer = "5mer"))
#> Considering 989 (99%) sites as homozygous...
#> Considering 887 (89.69%) sites as background (homozygous sites only)...
#> Considering 8 (0.81%) sites as high-signal site candidates (homozygous sites only)...
head(res$homosites[, c("pos", "motif", "beta_est", "posterior")])
#>              pos motif       beta_est posterior
#> 1 chr1_1233912_+ ACUUU 0.000001006474 0.9978190
#> 2 chr1_1233913_+ CUUUC 0.000001006474 0.9978190
#> 3 chr1_1233914_+ UUUCC 0.062045505136 0.9960682
#> 4 chr1_1233917_+ CCUUU 0.037124010384 0.9969108
#> 5 chr1_1233918_+ CUUUC 0.161731496908 0.9907397
#> 6 chr1_1233919_+ UUUCA 0.037124010384 0.9969108
```
